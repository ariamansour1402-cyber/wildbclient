# Custom PvP Client (Minecraft 1.8.9, Forge)

Fair-play client: HUD + quality-of-life only.

Features: FPS, CPS, Coordinates, Armor Status, Keystrokes (draggable HUD),
Toggle Sprint, Zoom (hold C), No Hurt Cam, settings menu (Right Shift).

## Get the ready-to-use build
1. Open the **Actions** tab of this repo and run **Build client** (it also runs on every push).
2. When it finishes, download the **CustomPvPClient** artifact (a zip).
3. Extract it and double-click `Install.bat`.
4. Open Minecraft Launcher, pick the `forge` profile, press Play.
